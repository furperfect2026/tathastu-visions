# Tathastu Website Project Plan

## Phase 1: Public Website Completion

Finish the customer-facing website first.

- Finalize homepage layout and CTAs
- Finalize Realty, Construction, Interior pages
- Replace placeholder/project images with real Tathastu photos
- Finalize services, projects, about, contact sections
- Add brochure download when PDF is ready
- Polish mobile/tablet responsiveness
- Verify all links, forms, social icons, map, phone, email
- Run final build and browser testing

## Phase 2: Content + Media Setup

Prepare website content properly.

- Organize image assets by category
- Compress and optimize images for fast loading
- Finalize project names, descriptions, locations, years
- Finalize service copy
- Finalize packages/pricing
- Finalize SEO titles and descriptions
- Add business schema/local SEO basics

## Phase 3: Backend + Leads

Make business inquiries reliable.

- Keep Supabase contact inquiry storage
- Keep Resend email notifications
- Add inquiry categories like Realty, Construction, Interior
- Add optional brochure/quote request type
- Add spam protection/rate limiting later if needed
- Test live email delivery after domain setup

## Phase 4: Admin Panel

Build a protected client dashboard.

- Admin login
- Dashboard overview
- Manage homepage slideshow images
- Manage service page images/content
- Manage projects
- Manage packages/pricing
- Manage contact info/social links
- View contact inquiries
- Mark inquiries as new/contacted/closed
- Upload brochure PDF
- Basic activity history

## Phase 5: Deployment

Launch the site.

- Push final code to GitHub
- Deploy on Vercel
- Add environment variables
- Connect GoDaddy domain
- Configure DNS
- Verify SSL
- Test live site on desktop/mobile
- Test contact form and email delivery

## Recommended Order

Public website first, admin panel second, deployment last. This keeps the site beautiful and stable before giving the client editing controls.
